\noindent The provided homework contains a programming assignment and no separate written questions. This document explains the methods used in the accompanying implementation.
\section{Line detection}
A Gaussian-smoothed grayscale image is processed by Canny edge detection. For every edge pixel $(x,y)$ and angle $\theta\in[0,\pi)$, the accumulator receives a vote at
\[
\rho=y\cos\theta-x\sin\theta,
\qquad x\sin\theta-y\cos\theta+\rho=0.
\]
Angles are sampled at one-degree intervals; distances use one-pixel bins over $[-D,D]$, where $D=\lceil\sqrt{H^2+W^2}\rceil$. Thus vertical lines do not require an infinite slope. The accumulator is normalized to an unsigned eight-bit image for the supplied runner.

Strong peaks are selected greedily, suppressing nearby distance and angle bins after each selection. At the angle boundary, equivalent representations $(\rho,\theta)$ and $(-\rho,\theta+\pi)$ are handled together. A line has point $(-\rho\sin\theta,\rho\cos\theta)$ and direction $(\cos\theta,\sin\theta)$. Edge support restricts the displayed segment to the observed object.
\section{Circle detection and coin values}
The calibration image supplies the nominal radii and denominations. For radius $r$, an edge pixel votes for candidate centers
\[
(a,b)=(x-r\cos\phi,\ y-r\sin\phi),\qquad \phi\in[0,2\pi).
\]
The implementation samples the circular perimeter explicitly and accumulates votes using NumPy. A small radius interval accommodates calibration error. Local center maxima generate circle candidates; circumference support scores compare candidates across radii. Greedy spatial suppression retains one hypothesis per coin while allowing adjacent and partially overlapping coins. On the plain background, thresholded silhouettes remove interior relief edges. The noisy-background case uses stronger smoothing to reduce text edges. Candidate circles must also have edge gradients aligned with their radial directions. We require 42\% angular support on plain backgrounds and 70\% on textured backgrounds.

Each retained radius is assigned to the nearest calibrated denomination within the specified tolerance. Values are summed in integer cents and converted to dollars only at the end, avoiding binary floating-point accumulation errors. No built-in line or circle Hough detector is used.
